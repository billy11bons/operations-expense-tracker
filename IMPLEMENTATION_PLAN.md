# Этап 2 — план сборки первой версии

Начало: 07.09.2026 16:58:00 UTC (12:58:00 America/New_York). Основание: явная команда пользователя «Да, продолжить». План составлен до создания кода.

1. Создать самостоятельный Next.js/TypeScript/Tailwind проект в `app/`, установить зависимости и сохранить lockfile. Все локальные кэши и результаты проверок размещать в папке кейса.
2. Выделить модель данных, точные денежные и календарные расчёты, демоданные и проверку схемы localStorage. Сохранять подтверждённое состояние только после успешной записи.
3. Собрать четыре маршрута: Dashboard, Expenses, Tasks, Settings / Categories. Реализовать CRUD, формы, статусы, фильтры, категории и пустые/ошибочные состояния. Простая светлая рабочая поверхность, тёмная навигация, зелёный акцент, без финального UI-polish.
4. Запустить первую версию и открыть локальный preview. Проверить сборку, навигацию, страницы, базовый CRUD, сохранение и основные расчёты. Сохранить скриншот первой версии. Исправлять блокирующие ошибки этапа 2, а не выполнять полную приёмку этапа 3.
5. Записать факты первого запуска в FIRST_RUN_NOTES.md, обновить PROJECT_LOG.md и только Шаг 2 WORKBOOK_CASE_01.md. Проверить расположение файлов и неизменность исходников.
6. Остановиться и запросить переход к этапу 3. Не публиковать, не создавать GitHub, не заполнять будущие тестовые отчёты.

Решение по инструментам: локальный Next.js scaffold вручную по официальной документации, поскольку согласованное ТЗ задаёт этот стек и все этапы до публикации должны оставаться локальными. Hosted Sites scaffold/регистрация не используются. Технические источники: https://nextjs.org/docs/app/getting-started/installation и https://tailwindcss.com/docs/installation/framework-guides/nextjs (просмотрены 07.09.2026).
